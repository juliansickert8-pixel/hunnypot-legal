3. Functionality

Server administrators can designate a honeypot channel. When an eligible member sends a message in that channel, the bot may automatically ban that member and request deletion of their messages from the previous seven days across the server using Discord's ban functionality. This action is irreversible for deleted messages. Actual enforcement depends on Discord permissions, role hierarchy, API availability, and bot configuration.

4. Administrator responsibilities

Server administrators are responsible for choosing appropriate channels, clearly communicating moderation rules, configuring role exclusions, testing the bot, and ensuring their use complies with applicable laws and Discord policies. Do not configure a honeypot in a channel where ordinary users are reasonably expected to communicate. Restrict configuration access to trusted staff.
