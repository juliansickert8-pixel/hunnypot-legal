# Hunnypot Legal Pages

Static GitHub Pages website for Hunnypot's English Terms of Service and Privacy Policy.

## Publish
1. Create a public GitHub repository named `hunnypot-legal`.
2. Upload `index.html`, `terms.html`, `privacy.html`, and `style.css` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main`, folder `/ (root)`, then **Save**.
6. Wait for deployment and open `https://YOUR_USERNAME.github.io/hunnypot-legal/`.
7. Configure Discord Developer Portal URLs:
   - Terms: `https://YOUR_USERNAME.github.io/hunnypot-legal/terms.html`
   - Privacy: `https://YOUR_USERNAME.github.io/hunnypot-legal/privacy.html`

## Before publication
- Verify the legal notice and contact email.
- Confirm privacy policy matches actual implementation and hosting.
- Specify and implement log retention/deletion.
- Confirm applicable GDPR legal bases and processors.
- Have legal documents reviewed for your jurisdiction.

This repository is static. It does not run the Discord bot.
